Android-only beta build for direct testing.

- Android version code: 21

## Fixes

- Matched the top theme, sound, and settings buttons with the legacy gradient icon style.
- Unified todo add/remove animation with priority and time-block rows.
- Reworked the mobile time-block layout so cards stay inside the panel and do not stretch awkwardly.
- Hid floating controls while the keyboard is open so fields are not covered during editing.
- Persisted todo selection state so copied/selected counts remain consistent after reload.
- Fixed the widget smoke test so it handles always-on UI animations without hanging.

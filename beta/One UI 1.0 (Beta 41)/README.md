# One UI 1.0 (Beta 41)

One UI 1.0 (Beta 41) 릴리즈 패키지입니다. 
이번 릴리즈는 테마 변경 시 설정 화면에서 배경색이 부자연스럽게 깜빡거리던 현상을 해결하여 시각적 완성도를 높였습니다.

## 릴리즈 정보
- **버전명**: One UI 1.0 (Beta 41)
- **빌드 번호**: 41
- **패키지 유형**: APK (Android)
- **배포 시간**: 2026년 5월 23일

---

## 주요 업데이트 및 변경 사항

### 1. 설정 화면 테마 깜빡임 문제 수정
* **배경 애니메이션 제거**: 설정 항목들을 감싸는 위젯에서 배경색 전환 애니메이션(`AnimatedContainer`)을 제거했습니다. 이를 통해 테마를 바꾼 뒤 이전 화면으로 돌아왔을 때 설정 항목의 배경색이 즉각적으로 반영되어, 잔상이 남거나 깜빡이는 현상을 완벽히 해결했습니다.

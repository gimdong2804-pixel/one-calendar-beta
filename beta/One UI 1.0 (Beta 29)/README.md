# One UI 1.0 (Beta 29) Release

## 변경 사항
- **실시간 백그라운드 업데이트 모니터링 서비스 탑재 (`flutter_background_service`)**:
  - 앱이 완전히 종료되어도 포그라운드 백그라운드 서비스가 가동되어 **정확히 1분 주기**로 최신 업데이트를 확인합니다.
  - 배터리 절전 정책으로 인해 서비스가 비정상 종료되는 것을 예방하기 위해, 알림창 상주형 '실시간 모니터링 알림'이 상시 노출됩니다.
- **네이티브 시스템 푸시 알림 발송 (`flutter_local_notifications`)**:
  - 서버의 최신 빌드가 현재 설치된 빌드보다 높은 새 소프트웨어가 감지되면 휴대폰 시스템 알림으로 알림창에 팝업을 발생시킵니다.
  - 알림 메시지에서 버전 이름과 체인지로그 변경 사항을 직관적으로 확인할 수 있도록 큰 텍스트 정보 형태를 적용했습니다.
- **지능형 인터넷 감지 및 자원 절약**:
  - 매 1분 작동 시 모바일 네트워크 또는 Wi-Fi 미연결 상태가 감지되면 업데이트 체크 로직을 완전히 생략(Skip)하여 배터리 및 네트워크 데이터를 철저하게 보호합니다.
- **알림 중복 완벽 제거**:
  - 동일한 업데이트에 대해 1분마다 계속 알림이 중복으로 울리는 현상을 막기 위해, 알림 발송이 확인된 빌드 번호는 `SharedPreferences` 로컬 저장소에 고정 기록하여 1회만 노출되도록 제어합니다.
- **우측 상단 더보기 내 데모 시뮬레이션 제거 및 미래 기능 플레이스홀더화**:
  - 기존에 테스트 용도로 존재하던 우측 상단의 '데모: 업데이트 있음', '업데이트 없음' 및 '초기화' 메뉴를 전면 삭제했습니다.
  - 향후 추가적인 다른 기능 탑재 시 유연하게 연동할 수 있도록 더보기 버튼 아이콘은 보존하되, 클릭 시 플레이스홀더 스낵바가 단정히 출력되도록 교체했습니다.

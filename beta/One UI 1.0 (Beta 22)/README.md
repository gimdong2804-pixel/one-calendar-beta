## Important Install Note

Beta 22 switches to a fixed release keystore. Devices with Beta 20 or older debug-key builds must uninstall the existing app before installing this APK. After Beta 22 is installed, future builds signed with the same release keystore can update normally.

## Fixes

- Switched Android release builds from machine-local debug signing to a fixed release keystore.
- Kept the Beta 21 UI fixes: unified floating settings icon color, todo animation consistency, mobile time-block layout stability, and keyboard overlap handling.

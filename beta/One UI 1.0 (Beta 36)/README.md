# One UI 1.0 (Beta 36)

One UI 1.0 (Beta 36) 릴리즈 패키지입니다. 
이번 릴리즈는 플래너 화면에서 핵심 목표 및 타임 블로킹 항목을 추가하거나 삭제할 때 발생하던 시각적 부자연스러움(그림자 깜빡임 및 잘림 현상)을 해결하여 더욱 매끄러운 사용자 경험을 제공하는 데 집중했습니다.

## 릴리즈 정보
- **버전명**: One UI 1.0 (Beta 36)
- **빌드 번호**: 36
- **패키지 유형**: APK (Android)
- **배포 시간**: 2026년 5월 23일

---

## 주요 업데이트 및 변경 사항

### 1. 플래너 인터페이스 시각적 안정화
* **항목 그림자 제거**: 핵심 목표(Priorities), 타임 블로킹(Time Blocks), 할 일 목록(Todos)의 각 개별 항목 카드에 적용되었던 그림자(`boxShadow`)를 완전히 제거했습니다. 이를 통해 리스트가 동적으로 변할 때 발생하던 불필요한 시각적 노이즈와 깜빡임 문제를 근본적으로 해결했습니다.
* **애니메이션 잘림 방지 (Clip.none)**: 영역의 높낮이가 조절되는 `AnimatedSize` 위젯에 `Clip.none` 설정을 적용하여, 애니메이션 도중 자식 위젯의 요소들이 경계선 밖으로 나갈 때 잘리는 현상을 수정했습니다.

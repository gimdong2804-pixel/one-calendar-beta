# One UI 1.0 (Beta 33) 릴리즈 노트

본 버전은 사용자 경험(UX) 극대화와 애플리케이션의 백그라운드 안정성 확보를 핵심 목표로 삼아 개발된 **One UI 1.0 (Beta 33)** 공식 배포본입니다. 

---

## 📢 주요 변경 및 개선 사항

### 1. 🔇 글로벌 터치 피드백(터치음) 제어 시스템 구축
* **문제 상황**: 소리 설정에서 소리를 명시적으로 껐음에도 불구하고 버튼 클릭이나 리스트 항목 터치 시 터치음(디바이스 피드백음)이 계속 발생하는 현상이 있었습니다.
* **개선 내용**: 
  - 애플리케이션의 핵심 테마(ThemeData)를 글로벌 설정값(`isSoundEnabled`)에 따라 실시간 동적으로 갱신하도록 설계 방식을 전면 개편했습니다.
  - `IconButton`, `ElevatedButton`, `OutlinedButton`, `TextButton`, `FilledButton`, `ListTile`, `PopupMenu`, `BottomNavigationBar` 등 기본 터치 피드백이 적용되는 모든 컴포넌트의 `enableFeedback` 상태를 설정 테마와 통합 연동시켰습니다.
  - 전용 플래너 화면의 커스텀 버튼 및 업데이트 세부 정보 화면 등 별도로 작성된 개별 `InkWell` 위젯들까지 `SettingsProvider` 상태를 주입받아 터치음을 글로벌 제어하도록 완벽하게 방어했습니다.

### 2. 🎛️ 소리 설정 전환 시 볼륨 슬라이더 애니메이션 고도화
* **문제 상황**: 소리 토글 스위치를 On/Off 할 때 볼륨 조절 영역이 즉각적으로 깜빡이듯 사라지고 나타나 시각적 부드러움이 결여되었습니다.
* **개선 내용**:
  - HSL 컬러 시스템이 적용된 프리미엄 다크/라이트 모드 설정 모달 내 소리 설정창 영역에 **고성능 마이크로 인터랙션**을 설계했습니다.
  - 볼륨 슬라이더 패널 영역을 `AnimatedSize`와 `AnimatedOpacity`의 콤보 레이아웃으로 감싸, 소리 설정을 끄거나 켤 때 영역의 높낮이가 부드럽게 늘어나고(Sliding) 페이드인/아웃(Fade)되는 고품격 트랜지션을 제공합니다.

### 3. 🔄 백그라운드 실시간 업데이트 확인 및 네이티브 푸시 알림 복원
* **문제 상황**: 신규 빌드가 배포되어도 백그라운드 Isolate 영역에서 로컬 알림 권한 및 플러그인 초기화 누락, 의존성 불일치 등으로 인해 업데이트 알림이 오지 않는 문제가 있었습니다.
* **개선 내용**:
  - `connectivity_plus`를 통합 연동하여 무선 환경 및 인터넷 끊김 상태 시 불필요한 네트워크 폴링을 효율적으로 차단하도록 설계했습니다.
  - Android 13 이상 기기에서의 네이티브 알림 권한(`requestNotificationsPermission`) 자동 획득 루틴을 보완했습니다.
  - 백그라운드 독립 Isolate 내부에서 `FlutterLocalNotificationsPlugin`의 완전한 다중 초기화(Multiple Initialization) 규격을 확립하여 백그라운드 1분 타이머 조회 도중 신규 빌드(`One UI 1.0 (Beta 33)`) 감지 시 기기 상단바에 확장 가능한 정식 클릭형 푸시 알림을 즉각적으로 발생시킵니다.
  - 포그라운드 상주 서비스 알림 내에 마지막 업데이트 확인 시간 분 단위 체크 정보를 제공하여 가시성을 확보했습니다.

# One UI 1.0 (Beta 32)

## 변경 사항
- **메뉴 명칭 대대적인 간소화**:
  - `테마 설정` $\rightarrow$ `테마`
  - `액션 바 커스텀` $\rightarrow$ `액션 바`
  - `애니메이션 설정` $\rightarrow$ `애니메이션`
  - `소리 설정` $\rightarrow$ `소리`
- **설정 메뉴 레이아웃 최적화 (모든 토글 제거 및 화살표 교체)**:
  - 설정 화면에서 스위치 형태의 토글 아이콘을 전면 삭제하고 모두 상세 설정 진입 화살표(chevron)로 디자인을 통일하여, One UI 특유의 심플하고 깨끗한 레이아웃을 극대화하였습니다.
- **테마 상세 설정 화면 추가 (`ThemeSettingsScreen`)**:
  - 기존 메인 화면에서 직접 설정하던 테마 토글을 상세 화면 내의 "다크 모드" 옵션(키고 끌 수 있음)으로 분리하여 배치하였습니다.
- **소리 상세 설정 화면 추가 (`SoundSettingsScreen`)**:
  - 기존 메인에 위치하던 소리 토글과 활성화 시 표시되던 볼륨 조절 슬라이더를 독립된 소리 설정 상세 화면으로 이동시켜, 설정 메인 화면의 시각적 복잡성을 대폭 낮추었습니다.

## Important Install Note

Devices with Beta 20 or older debug-key builds must uninstall the existing app before installing this APK. After Beta 22 is installed, future builds signed with the same release keystore can update normally.

- 설정의 "업데이트 확인" 타이틀을 "소프트웨어 업데이트"로 변경하였습니다.

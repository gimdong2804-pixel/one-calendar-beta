# One UI 1.0 (Beta 2)

Android-only beta build for direct testing.

- App label: One Calendar Beta
- Android version name: 1.0.0-beta.2
- Android version code: 2
- APK: `One UI 1.0 (Beta 2).apk`
- SHA256: `00A82128335A36DA0C2D16B659F6CA6582C20BC57962418249B99E253F13F087`

## Fixes

- Matched the top theme, sound, and settings buttons more closely to the legacy One UI outline/gradient icon style.
- Added safe-area spacing so the mobile date dock and floating buttons no longer sit under the Android status bar.
- Reworked the mobile priority header so the title, subtitle, and todo-toggle button follow the legacy vertical layout.
- Clamped Android system text scaling to keep the planner readable like the legacy web version.
- Changed the empty priority default to one item and collapsed previously empty multi-item defaults.
- Made mobile priority input cards roomier and closer to the legacy card shape.
- Restyled add buttons to the quieter white pill style used by the legacy UI.

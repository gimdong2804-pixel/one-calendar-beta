# One UI 1.0 (Beta 28)

## 변경 사항
- **One UI 1.0 브랜드 통일**: 중앙 타이틀 로고명을 기존 One UI 8.5에서 One UI 1.0으로 일관되게 정정
- **프리미엄 4-도트 회전 로딩 애니메이션**: 성능 병목 현상이 있었던 물결 운동식 도트 로딩을 하드웨어 가속 기반의 부드러운 원형 회전식 4-도트 로더로 전면 교체하여 지터(Jitter) 현상 제거
- **최신 소프트웨어 문구 정렬 최적화**: 텍스트 간격을 축소(top: 4)하여 메인 로고 영역과 자연스럽게 결합되도록 배치 상향
- **완벽한 라이트 모드(밝은 화면) 레이아웃 대응**: 기존에 어두운 디자인만 강제 출력되던 현상을 해결하여, 기기의 라이트 모드 설정 시 밝은 배경에 깔끔하고 모던한 검은색 계열 텍스트/카드 디자인이 자동 전환 처리되도록 보완
- **상단 손잡이 드래그 제스처 지원 접이식 카드 설계**: 디테일 화면을 `DraggableScrollableSheet` 스냅 컨테이너 기반으로 구조 변경하여 회색 드래그 바를 위로 올릴 시 Wallpaper 영역이 Parallax 축소되며 내역 페이지가 전면 확장되고, 내릴 시 부드럽게 복구되는 감각적인 One UI 제스처 통합
- **인라인 버튼 다운로드 진행률 바 전환 기술**: 다운로드 버튼 클릭 시 팝업을 띄우지 않고, 버튼 자체가 트랙 형태의 실시간 설치 게이지 바로 변형되어 채우기 애니메이션과 파일 다운로드 용량 통계(`48% (26.5 MB / 55.7 MB)`)가 실시간 투영되도록 인라인 변환 설계 구현

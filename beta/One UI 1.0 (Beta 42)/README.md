# One UI 1.0 (Beta 42)

One UI 1.0 (Beta 42) 릴리즈 패키지입니다. 
이번 릴리즈는 사용자의 사용 패턴에 맞게 하단 액션 바(Action Bar)를 자유롭게 커스터마이징할 수 있는 기능을 추가하여, 한층 더 정돈되고 유려한 One UI 홈 스크린 경험을 선사합니다.

## 릴리즈 정보
- **버전명**: One UI 1.0 (Beta 42)
- **빌드 번호**: 42
- **패키지 유형**: APK (Android)
- **배포 시간**: 2026년 5월 24일

---

## 주요 업데이트 및 변경 사항

### 1. 하단 액션 바 커스터마이징 기능 구현
* **버전별 정렬 및 표시 제어**: 설정 메뉴 내 새롭게 추가된 '액션 바' 커스텀 화면에서 `ReorderableListView`를 사용하여 각 버튼의 표시 순서를 드래그 앤 드롭으로 자유롭게 제어할 수 있습니다. 우측 스위치 토글을 통해 자주 쓰지 않는 기능 버튼을 감추는 것도 가능합니다.
* **배경 블러(Blur) 세기 제어**: 하단 액션 바의 세련된 투명 배경 블러 효과(Backdrop Blur)의 강도를 0부터 50까지 정교하게 조절할 수 있는 슬라이더(Slider)가 탑재되었습니다.

### 2. 레이아웃 렌더링 및 빌드 이슈 수정
* **버전 빌더 컴파일 에러 해결**: 액션 바 내부의 개별 버튼 위젯(`_ActionButton`) 생성자에 `super.key` 매개변수를 정상 정의하여, 동적 순서 렌더링 시 발생하던 Flutter 컴파일 에러를 완벽하게 해결했습니다.

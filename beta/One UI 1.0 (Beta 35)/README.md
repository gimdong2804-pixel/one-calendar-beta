# One UI 1.0 (Beta 35)

One UI 1.0 (Beta 35) 릴리즈 패키지입니다. 
이번 릴리즈는 사용자가 보고한 앱 기동 후 강제 종료(Crash) 및 무한 크래시 루프 문제를 근본적으로 예방하고, 개발 환경에서 지속적으로 보고된 코드 경고 항목들을 완벽히 정비하여 시스템 안전성을 극적으로 향상시키는 데 집중했습니다.

## 릴리즈 정보
- **버전명**: One UI 1.0 (Beta 35)
- **빌드 번호**: 35
- **패키지 유형**: APK (Android)
- **배포 시간**: 2026년 5월 22일

---

## 주요 업데이트 및 변경 사항

### 1. 백그라운드 서비스 런타임 안정화 및 강제 종료 방지
* **`connectivity_plus` 채널 의존성 완전 배제**: 백그라운드 Isolate 런타임 환경에서 플랫폼 네트워크 채널 연동(Connectivity) 과정에서 플러그인 유실(`MissingPluginException`)로 유발되던 강제 종료 현상을 완전히 해결했습니다.
* **소켓 기반 자동 예외 복구**: 네트워크가 없으면 `HttpClient` 단에서 발생하는 소켓 에러를 내부 try-catch를 통해 조용히 방어 복구하며, 백그라운드 업데이트 모니터링 생명주기가 영구히 유지되도록 안전장치를 구축했습니다.
* **초강력 전역 예외 방어막**: `onStart` 진입점의 메인 스레드 구조 전체 및 비즈니스 로직 전체를 촘촘히 래핑하여 런타임 단절을 원천 방지했습니다.

### 2. 최신 Flutter API 마이그레이션 및 코드 경고(Lint) 완벽 해소
* **Deprecated API 교체**: 소프트웨어 업데이트 화면 및 상세 안내 위젯 전역에서 경고로 지적되던 `withOpacity` 메소드를 최신 명세인 `.withValues(alpha: ...)`로 완벽히 리팩토링했습니다.
* **미사용 필드 제거**: `SoftwareUpdateScreen` 내부에서 선언된 뒤 참조되지 않던 `_demoUpdateInfo` 필드를 깨끗이 제거하여 빌드 경고와 메모리 낭비를 줄였습니다.
